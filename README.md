# PatrizioMoi-PCBFixes

Each product is a audio instrument, where the ESP32 receives audio signals from Ethernet ports (so the Ethernet port and ESP32 must communicate well), and each knob/button/toggle switch sends value signals to the ESP32 for audio processing. The way the audio will be processed it's not an issue right now, because it will be programmed by audio specialist. Your job is to design the 4 PCBS above in a way that

(i) each rotary switch, potentiometers, toggle switch, buttons, etc is aligned wiht the silkscreen and connected to the right pins;  
(ii) each rotary switch, potentiometers, toggle switch, buttons, etc sends signals to the ESP32 correctly;  
(iii) the entire PCB is well powered and fully functioning as desired.
